# V5：保留原建模，补齐自动取证与元素对齐

普通用户只提供本地PDF或论文网址，两者任选其一。无需手填仓库、权限、信息流、实例关系或人工标签；输出目录自动生成。

```bash
python3 -B scan.py /path/to/paper.pdf
python3 -B scan.py https://arxiv.org/abs/2605.17324v1
```

输出仍每篇一条：`inconsistency=true`为确认不一致，`false`为固定审计范围内怀疑已排除，`null`为未能确认或运行未完成。确认项的`findings`给出具体分支、论文页码、代码文件/行号、固定版本和源码链接。HTML/JSON报告保留所有依据；不把不确定当阴性。

CLI默认源码预算500,000字符，模型数据JSON上限1,200,000字符；必要依赖另有独立限额，所有遗漏保留。单参数入口沿用账号配置，不需要指定模型或仓库。这些是输入限额，不是费用上限。

## 底层逻辑

继续使用此前的声明模型$\Gamma_{decl}$与实现证据$D_{impl}$。两端都归一化到五元信息流：角色、阶段、来源、表示和用途，另以论文版本、代码版本、实验分支、配置约束范围。V5不是替换这一模型，而是增加角色与实例绑定的引用、独立复核和确定性验收。

公式与具体函数的一一对应见 [Notion建模与代码映射](NOTION_MODEL_MAPPING_ZH.md)。比较规则已落地不等于自动抽取已准确，需要分别报告软件检查与原始论文实验。

在适用范围对齐且证据无冲突时，明确禁止＋确认交付仍判不一致。明确授权可以排除该“禁止访问”怀疑，无需额外强求访问实际发生；整个论文的范围内阴性仍要求非空的全部所列怀疑均被排除、证明义务闭合，不删除未决项来得到阴性。

## 实现改动

1. `evidence_expansion.py` 从实际代码import、literal路径和配置模板静态计算Needed；`source_bundle.py` 在固定版本内迭代补配置和相关文件，并通过`.gitmodules`与固定gitlink取得一层公开GitHub依赖。不会安装或执行依赖。每个新增材料保留原始内容/hash，超限、动态路径或无法固定来源明确保留未解析。
2. `extraction_v5.py` 在原五元edge上显式增加接收者、攻击者交付、实例要求，以及配置/稳定ID/索引变换映射。实例same/different需至少两处独立定位和模型复核；train/test名称和文本相同不能单独证明身份。
3. `scope_review.py` 新分支只处理经验证的V5绑定。evaluator收到query与attacker收到query分开，观察evaluator不会自动排除attacker。类别限制不强求同一评估实例；针对某评估实例的限制才需要same-instance证明。优化器本身受限时，以其输入为终点，不额外要求后续LLM或victim交付。
4. `findings.py` 将论文级判定投影为三值答案与具体位置。`scan.py` 默认使用V5源码审计，`--engine-version 4`保留历史比较；无源码时仍保留论文文本路径和材料缺口。

V2/V3/V4历史记录保留。101条旧规范化记录与旧scope实现输出逐对象相同；这属于兼容性验证，不是端到端检测准确率。

## 闭合和限额

定向取证最多8轮，额外文件、数据和字符均有独立限额。较大数据集不会被静默塞进模型；超限将保留来源/路径缺口。MUZZLE依赖是固定版本的Git子模块，而不是安装任意当前版本。子仓库单独验证后挂载到同一证据图，引用仍返回子仓库自身commit与真实路径。

模型看到必要源码、配置与简洁的版本/覆盖信息。完整下载账本、Git树和溯源仍保存并参与输入绑定，不重复塞进模型正文。角色和映射语义由另一次模型调用复核，确定性代码检查引用、绑定和状态一致性；这不是通用程序语义证明，也不证明作者历史执行或ASR变化。

V5.1补齐了模型输出契约：路径节点须连续命名，终点引用须落在同一输入调用；Python多行调用以不执行代码的AST调用跨度核验，避免用两行距离截断长参数列表。条件静态实例证明与作者历史运行分开；权限未确认时，仍保留待证明实例关系的独立缺口。原V5真实运行保留作比较。

V5.2将Python调用验收收紧为字符位置上的同一最内层调用，区分嵌套的不同接收者及同一行的两个调用。稳定ID若是AST元组，可逐分量验收；每侧仍需一处同时包含所有分量的精确引用、独立的源/评估定位和复核通过的变换链。不会执行表达式、按逗号乱拆文本或忽略缺失ID分量。历史自动输出的重新验收单独标为deterministic revalidation，不冒充新增模型实验。

所需材料未闭合时保留不确定。已有充分局部正证据不因无关依赖缺失被撤销；阴性只涵盖固定的所列怀疑和分支，不能认证整篇所有行为。
